# Поиск информации в базе знаний

## Результат

Ответь на вопрос по материалам репозитория, покажи дату их проверки и приложи исходные ссылки. Эта процедура ничего
не изменяет в репозитории.

## Порядок работы

1. Прочитай `README.md` и выбери документы, чьи названия, описания или теги относятся к запросу.
2. Останови поиск по репозиторию, когда найденные документы покрывают вопрос или индекс не содержит подходящей темы.
3. Отдели сведения из базы от собственных выводов.
4. Если пользователь спрашивает о текущем состоянии, а факт может меняться, открой официальный источник заново.
5. Если документ имеет статус `needs-review` или `archived`, явно сообщи об этом до вывода.
6. Если свежий источник расходится со статьёй, опиши расхождение. Не редактируй документ без отдельного запроса.
7. Дай ссылки на локальные документы и первичные источники рядом с соответствующими утверждениями.

## Границы

- Не считай дату `last_updated` доказательством актуальности; используй `last_verified`.
- Не выдавай отсутствие темы в базе за отсутствие функции у продукта.
- Не используй вторичный источник вместо доступной официальной документации без пояснения.

## Пример результата

```markdown
По статье, полностью проверенной 2026-09-23, Codex собирает AGENTS.md от корня проекта до рабочей директории.
Текущая документация OpenAI подтверждает этот порядок. Источники: статья базы, документация OpenAI.
```
