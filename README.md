# AI Knowledge Base

Открытая база знаний об AI-инструментах, агентных средах и практиках работы с ними.

Здесь собраны не только пересказы документации, но и результаты проверок. Каждое изменяемое во времени утверждение
должно вести к источнику, чтобы человек или агент мог повторно проверить его актуальность.

## Принципы

- В приоритете официальная документация, спецификации и исходный код.
- Факт, результат эксперимента и авторский вывод обозначаются отдельно.
- У каждой статьи есть дата последней полной проверки.
- Частичное дополнение не считается полной проверкой статьи.
- Если официальные источники расходятся или не дают ответа, неопределённость сохраняется в тексте.
- Устаревший материал помечается, а не удаляется без объяснения, если он полезен как исторический контекст.

## Статусы документов

| Статус | Значение |
| --- | --- |
| `current` | Все существенные утверждения проверены по указанным источникам |
| `needs-review` | Часть утверждений требует повторной проверки |
| `archived` | Документ сохранён для истории и не описывает текущую практику |

Поле `last_verified` меняется только после полной проверки статьи. При локальном дополнении меняется
`last_updated`, а новая информация получает собственный источник и дату проверки.

## Типы документов

Для объяснений, сравнений и практических руководств используется [шаблон статьи](templates/article.md).

Для воспроизводимых проверок поведения инструмента используется [шаблон эксперимента](templates/experiment.md).
Эксперимент фиксирует окружение, шаги, ожидаемый и фактический результат. Его вывод нельзя автоматически считать
свойством всех версий продукта.

## Требования к источникам

1. Используйте первичный источник, если он существует.
2. Ставьте ссылку рядом с утверждением, которое она подтверждает.
3. В разделе `Источники` указывайте владельца, тип источника и дату проверки.
4. Для поведения, установленного экспериментом, прикладывайте шаги воспроизведения.
5. Не выдавайте отсутствие информации в документации за доказательство отсутствия функции.

Пример записи:

```markdown
- [Custom instructions with AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md)
  — OpenAI, официальная документация, проверено 2026-09-23.
```

## Работа через агента

В репозитории есть четыре процедуры:

| Задача | Codex | Claude Code |
| --- | --- | --- |
| Найти информацию | `$find-ai-knowledge` | `/find-ai-knowledge` |
| Добавить документ | `$add-ai-document` | `/add-ai-document` |
| Полностью обновить документ | `$refresh-ai-document` | `/refresh-ai-document` |
| Дополнить существующий документ | `$extend-ai-document` | `/extend-ai-document` |

Общие процедуры находятся в `agent-workflows/`. Файлы в `.agents/skills/` и `.claude/skills/` подключают их к
конкретной агентной среде.

## Проверка репозитория

После изменения документов или скиллов выполните:

```bash
python3 scripts/validate_docs.py
```

Проверка не обращается к сети. Она проверяет frontmatter, даты, статусы, раздел источников, локальные ссылки и
базовый формат скиллов.
