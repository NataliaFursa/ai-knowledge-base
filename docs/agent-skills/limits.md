# Лимиты скиллов и файлов инструкций

> Значения проверены 2026-09-23. Перед использованием числового ограничения повторно откройте источник: вендоры
> могут менять лимиты между версиями.

## Общий формат Agent Skills

| Элемент | Ограничение или рекомендация |
| --- | --- |
| `name` | 1–64 символа; строчные латинские буквы, цифры и дефисы; без дефиса по краям и `--` |
| Имя каталога | Должно совпадать с `name` |
| `description` | 1–1024 символа; описывает результат и условия применения |
| `compatibility` | Необязательное поле до 500 символов для требований к окружению |
| Метаданные на этапе обнаружения | Около 100 токенов на скилл |
| Основная часть `SKILL.md` | Рекомендуется менее 5000 токенов и менее 500 строк |
| Дополнительные материалы | Загружаются по необходимости |
| Ссылки из `SKILL.md` | Рекомендуется один уровень вложенности без длинных цепочек |

Поля `license`, `metadata` и экспериментальное `allowed-tools` необязательны. Поддержка `allowed-tools` зависит от
конкретного клиента.

## Claude Code

| Элемент | Ограничение или рекомендация |
| --- | --- |
| `CLAUDE.md` | Рекомендуется держать короче 200 строк |
| Импорт `@path` | Поддерживается до четырёх последовательных переходов |
| Проектный скилл | `.claude/skills/<name>/SKILL.md` |
| Прямое чтение `AGENTS.md` | Claude Code 2.1.277 или новее; доступно не во всех окружениях |
| Основная часть скилла | Загружается при вызове или автоматическом выборе |

Claude Code допускает отсутствие `name` в локальном скилле и использует имя каталога как имя команды. Для
переносимого скилла всё равно указывайте и `name`, и `description`, поскольку этого требует общая спецификация.

Вендорские поля frontmatter могут менять видимость, способ вызова и разрешённые инструменты. Перед использованием
такого поля сверяйте его с документацией Claude Code, а не переносите по аналогии в другой клиент.

## OpenAI Codex

| Элемент | Ограничение или рекомендация |
| --- | --- |
| Общий размер цепочки инструкций | `project_doc_max_bytes`, по умолчанию 32 KiB |
| Файлы в одном каталоге | Не больше одного: override, основной файл или настроенный fallback |
| Пустой файл инструкций | Не включается в цепочку |
| Проектный скилл | `.agents/skills/<name>/SKILL.md` |
| Полный `SKILL.md` | Загружается после выбора скилла |

Если цепочка `AGENTS.md` достигает лимита, увеличьте `project_doc_max_bytes` или перенесите узкие правила ближе к
каталогу, где они применяются. Не увеличивайте лимит только для хранения справочных материалов: для них лучше
использовать скилл.

## Практический вывод

- Держите постоянные инструкции короткими и применимыми к большинству задач.
- Делайте `description` различающим, но не превращайте его в процедуру.
- Храните редкие подробности в справочных файлах скилла.
- Проверяйте числовые лимиты перед публикацией статьи, шаблона или инструмента, который от них зависит.
