# Agent Skills в Claude Code и OpenAI Codex

Скилл — это повторно используемый набор инструкций и материалов для одной распознаваемой задачи. Он хранится в
директории с обязательным файлом `SKILL.md` и может включать справочники, шаблоны и скрипты.

Claude Code и Codex поддерживают открытый формат Agent Skills. Пути обнаружения и вендорские расширения могут
различаться, но переносимое ядро строится одинаково.

## Когда нужен скилл

| Механизм | Когда применять |
| --- | --- |
| `CLAUDE.md` или `AGENTS.md` | Правило нужно в большинстве задач проекта |
| Скилл | Повторяется отдельная процедура или нужен большой справочный материал по запросу |
| MCP или коннектор | Требуется доступ к живым данным или внешней системе |
| Сабагент | Нужна изоляция контекста или самостоятельное исследование |

Один скилл должен соответствовать одной цели. Процедуры с разными условиями запуска, входами или критериями успеха
лучше разделять.

## Progressive disclosure

Скилл загружается поэтапно:

1. При обнаружении агент видит `name` и `description`.
2. При выборе скилла читается полный `SKILL.md`.
3. Справочники читаются, а скрипты запускаются только при необходимости.

Поэтому `description` должно ясно называть результат и условия запуска, а подробная процедура должна находиться в
основной части. Условные материалы следует выносить в `references/`, `assets/` и `scripts/`.

## Структура

```plain
writing-module-docs/
  SKILL.md
  references/
  scripts/
  assets/
```

Обязателен только `SKILL.md`.

```markdown
---
name: writing-module-docs
description: Writes a module README from its public API. Use when the user asks to document a module.
---

# Документация модуля

1. Прочитай публичный API и файл сборочной конфигурации модуля.
2. Предложи структуру README и дождись подтверждения.
3. После подтверждения напиши документ.
4. Сверь каждое утверждение с кодом.

Если модуль не определён однозначно, остановись и запроси путь.
```

Поле `name` должно совпадать с именем каталога. Поле `description` сообщает агенту, когда загружать инструкцию, и
не должно превращаться в полный перечень шагов.

## Пути хранения

| Область | Claude Code | OpenAI Codex |
| --- | --- | --- |
| Проект | `.claude/skills/<name>/SKILL.md` | `.agents/skills/<name>/SKILL.md` |
| Пользователь | `~/.claude/skills/<name>/SKILL.md` | `~/.agents/skills/<name>/SKILL.md` |

Claude Code обнаруживает проектные скиллы в директории запуска и выше до корня репозитория. Вложенный скилл может
стать доступным, когда Claude начинает работать с файлами соответствующей подпапки.

Codex ищет проектные скиллы от текущей рабочей директории вверх до корня проекта. Для гарантированного обнаружения
вложенного скилла запускайте Codex из этой подпапки или ниже.

## Содержание инструкции

Хорошая инструкция определяет:

- область применения и близкие задачи, которые в неё не входят;
- обязательные входные данные;
- порядок действий там, где он влияет на результат;
- ожидаемый артефакт или формат ответа;
- сведения, которые нельзя предполагать;
- условия остановки и запроса уточнений;
- дополнительные файлы и момент их загрузки;
- короткий пример результата, если его форма важна.

Запрет должен содержать безопасное продолжение. Вместо «не придумывай версию» напишите: «Возьми версию из поля
`version` в `package.json`; если поля нет, запроси значение».

Если сбор контекста может стать бесконечным, задайте границу. Например: «Прочитай публичные типы и `.asmdef`; не
открывай внутренние типы, если публичный API на них не ссылается».

## Уровень детализации

| Уровень | Форма | Когда применять |
| --- | --- | --- |
| Высокая свобода | Критерии и ограничения | Есть несколько правильных решений |
| Средняя свобода | Шаблон или псевдокод | Есть предпочтительная форма с допустимыми вариациями |
| Низкая свобода | Точная команда или последовательность | Ошибка опасна или результат должен быть воспроизводимым |

Избыточная детализация может ограничить модели без пользы. Добавляйте правила по наблюдаемым ошибкам, а не по всем
воображаемым сценариям.

## Вендорские расширения

Claude Code поддерживает дополнительные поля frontmatter для управления вызовом, разрешёнными инструментами,
аргументами и контекстом выполнения. OpenAI может хранить интерфейсные настройки и зависимости в
`agents/openai.yaml`.

Не добавляйте вендорское поле в переносимое ядро без необходимости. Если расширение нужно, отделите его от общей
процедуры и проверьте поведение в каждом клиенте.

## Проверка скилла

Проверяйте отдельно выбор скилла и качество результата:

1. Прямой запрос должен активировать скилл.
2. Косвенный запрос с той же целью тоже должен его активировать.
3. Неполные данные должны привести к нужному вопросу.
4. Похожая неподходящая задача не должна активировать скилл.
5. Граничный случай не должен приводить к выдуманным данным или неподдерживаемому действию.

Если скилл не выбирается, исправляйте `description`. Если он выбирается верно, но нарушает процедуру, исправляйте
основную инструкцию.
