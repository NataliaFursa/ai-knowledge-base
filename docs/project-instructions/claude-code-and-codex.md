# Инструкции проекта в Claude Code и OpenAI Codex

Файлы инструкций содержат сведения, которые агент должен учитывать при работе с репозиторием: команды сборки,
структуру проекта, соглашения, ограничения и критерии завершения задачи.

Инструкции входят в контекст модели и направляют её поведение. Они не заменяют разрешения, песочницу и другие
технические ограничения.

## Основные файлы

| Вендор | Основной файл | Когда загружается |
| --- | --- | --- |
| Anthropic Claude Code | `CLAUDE.md` | При запуске; вложенные файлы могут загружаться при работе в подпапке |
| OpenAI Codex | `AGENTS.md` | При запуске; цепочка строится от корня проекта до рабочей директории |

Claude Code также умеет читать `AGENTS.md`. По умолчанию он использует его, только если в рабочей директории и
выше нет `CLAUDE.md`, `.claude/CLAUDE.md` или `CLAUDE.local.md`. Прямое чтение `AGENTS.md` требует Claude Code
2.1.277 или новее и доступно не во всех окружениях.

## Что хранить в инструкциях

В постоянные инструкции помещают сведения, необходимые во многих задачах:

- команды сборки и тестирования;
- расположение важных частей проекта;
- соглашения по коду и документации;
- устойчивые ограничения;
- критерии готовности результата.

Многошаговую процедуру для одного вида работы лучше оформить как скилл. Например, правило об отступах относится
к инструкциям проекта, а последовательность публикации релиза — к скиллу.

## Как писать правила

Правило должно описывать проверяемое действие или артефакт.

Недостаточно конкретно:

```plain
Проверь изменения.
```

Конкретно:

```plain
Перед завершением запусти сборку решения и убедись, что ошибок компиляции нет.
```

Используйте заголовки и списки, удаляйте устаревшие правила и не оставляйте одновременно действующие
противоречия. Более близкий файл может получить больший приоритет, но это не делает конфликт безопасным.

## Где находятся инструкции

| Область | Claude Code | OpenAI Codex |
| --- | --- | --- |
| Пользователь | `~/.claude/CLAUDE.md` | `~/.codex/AGENTS.md` |
| Проект | `./CLAUDE.md` или `./.claude/CLAUDE.md` | `./AGENTS.md` |
| Локальные настройки проекта | `./CLAUDE.local.md` | Используется `AGENTS.override.md` |
| Подпапка | `CLAUDE.md` или `CLAUDE.local.md` | `AGENTS.md` или `AGENTS.override.md` |

## Как Claude Code загружает инструкции

Claude Code загружает `CLAUDE.md` и `CLAUDE.local.md` из рабочей директории и каталогов выше неё. Найденные файлы
объединяются от корня файловой системы к рабочей директории. Файлы из дочерних директорий подключаются позже,
когда Claude читает файлы в этих директориях.

Дополнительные файлы можно импортировать синтаксисом `@path/to/file`. Относительный путь считается от файла,
содержащего импорт. Поддерживается до четырёх переходов между импортами. Импорт помогает организовать текст, но
не уменьшает расход контекста.

Для крупных проектов правила можно вынести в `.claude/rules/`. Поле `paths` ограничивает правило файлами,
соответствующими указанным glob-шаблонам.

## Как Codex загружает инструкции

Codex строит цепочку один раз при запуске:

1. В `CODEX_HOME`, обычно `~/.codex`, выбирается `AGENTS.override.md` или, если его нет, `AGENTS.md`.
2. От корня проекта до текущей рабочей директории Codex проверяет каждый каталог.
3. В каталоге выбирается первый непустой файл: `AGENTS.override.md`, `AGENTS.md`, затем настроенное запасное имя.
4. Файлы объединяются от корня к рабочей директории, поэтому более близкая инструкция оказывается позже.

Если корень проекта не найден, проверяется только текущая рабочая директория. Codex не продолжает поиск ниже неё
только потому, что позднее открыл файл из дочерней папки.

Общий размер цепочки ограничен параметром `project_doc_max_bytes`; значение по умолчанию — 32 KiB. Запасные имена
задаются в `project_doc_fallback_filenames`.

## Совместимый репозиторий

Общие правила удобно хранить в `AGENTS.md`. Для Claude Code можно создать короткий `CLAUDE.md`:

```markdown
@AGENTS.md
```

Так Codex читает общий файл напрямую, а Claude Code получает его через поддерживаемый импорт. Отдельные правила
Claude Code можно добавить в `CLAUDE.md` ниже импорта.

Другой вариант — включить в Claude Code режим `claude-md-and-agents-md`. Он является пользовательской настройкой,
поэтому репозиторий не может полагаться на него для всех участников.

## Проверка загрузки

| Вендор | Проверка |
| --- | --- |
| Claude Code | Выполнить `/context` и проверить раздел Memory files |
| OpenAI Codex | Запустить `codex --ask-for-approval never "Summarize the current instructions."` |
| Codex из подпапки | Передать `--cd <подпапка>` и запросить список активных инструкций |

Если Codex показывает устаревшую цепочку, запустите новую сессию в нужной рабочей директории.
